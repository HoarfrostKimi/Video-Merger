# 重构后手工冒烟测试清单

重构原则：**功能完全不变**。请在浏览器里按以下 4 项验证重构后的插件行为与重构前一致。

## 前置步骤

1. 确认已执行 `npm run build`（产物 `dist/content.js` 是最新的）
2. 打开 `chrome://extensions` → 找到「B站投稿助手」→ 点击**重新加载**（manifest 已改为加载 `dist/content.js`）
3. 打开 B站投稿页：https://member.bilibili.com/platform/upload/video/frame

## 验证项

### ① 单视频上传（标题=日期前置）
- [ ] 选择 1 个 `2026-07-17_我的视频_合并版.mp4` 文件，点「开始自动上传」
- [ ] 上传完成后标题框内应填成 `2026-07-17 我的视频`（日期保留并前置）
- [ ] 日志出现「已点击「立即投稿」→ 投稿已提交」两步
- [ ] B站后台稿件列表出现该视频

### ② 批量分P
- [ ] 选择 2-3 个视频（文件名带不同日期，如 `2026-07-17_xxx.mp4`、`2026-07-18_xxx.mp4`）
- [ ] 第一个视频走完整流程；后续走「添加分P」流程
- [ ] 主标题 = 第一个视频的「日期 标题」；分P标题 = 各视频文件名（默认）
- [ ] 全部处理完成后日志出现「===== 全部处理完成 =====」

### ③ 错误包复制
- [ ] 面板日志区出现「📋 复制错误包（粘贴给 AI）」按钮
- [ ] 点击后按钮短暂变「✅ 已复制」，粘贴出来是完整 Markdown（含基本信息/日志/DOM 快照/源码）
- [ ] 没有错误报告时点击提示「暂无错误报告」

### ④ autoFiles 联动（配合视频合并 app）
- [ ] 从视频合并 app 发起投稿，页面自动带 `?autoFiles=...` 参数打开
- [ ] 自动下载文件、批量上传、最后发 `signal=done` 通知 app 关闭
- [ ] 上传期间把窗口最小化再切回，日志出现「页面曾被隐藏 N 秒」节流警告

## 失败时的处理

任一项失败：点「📋 复制错误包」→ 把内容发给 AI 或开发者即可定位。错误报告存于 B站页面域 localStorage，刷新不丢。
